# Void Pointer with memmove()

## Author
M.Likitha

## Description
This program demonstrates how void pointers can be used
with the memmove() function.

The contents of an integer array are copied into another
integer array using memory addresses stored in void pointers.

## Concepts Used
- Void pointer
- memmove()
- Integer arrays
- Memory copying
- sizeof operator

## How to Run

gcc void_pointer_memmove.c -o void_pointer_memmove

./void_pointer_memmove

## Sample Output

Source array: 10 20 30 40 50
Destination array: 10 20 30 40 50
